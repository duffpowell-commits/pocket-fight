# Release marketing gate

- [ ] Build launches on intended target; game title, studio splash and publisher credits verified.
- [ ] Actual release URL and version recorded; playable/demo claims checked.
- [ ] Approved screenshots, trailer and press-kit assets correspond to shipped content.
- [ ] CTA and landing page link tested on phone.
- [ ] Platform-specific captions and media quality reviewed; sound and subtitles present.
- [ ] Exact publication dates and platforms approved.
- [ ] Each scheduled item has an external platform confirmation ID and timezone.
- [ ] Public post URLs verified after publication.
- [ ] 24-hour and seven-day review planned; no unverified numbers reported.

**Gate:** Unchecked items remain pending. No paid campaign without separate budget approval.
